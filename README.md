# Metric/Imperial Unit Converter

A clean, responsive web application to convert metric and imperial units. Built from scratch using HTML, CSS (Flexbox), and Vanilla JavaScript.

## Features
* **Length Conversion:** Meters <-> Feet
* **Volume Conversion:** Liters <-> Gallons
* **Mass Conversion:** Kilograms <-> Pounds
* Sleek, modern user interface.

## Getting Started
Install the dependencies and run the project locally using Vite:
```bash
npm install
npm start
```
